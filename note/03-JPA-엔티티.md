# 03단원: JPA + 엔티티 (Question)

## 🧠 머릿속 그림 요약
`@Entity` 붙은 자바 클래스 1개 = DB 테이블 1개. 필드 = 컬럼. Hibernate(JPA 구현체)가 `ddl-auto: update` 설정을 보고 앱 기동 시 `CREATE TABLE`을 자동 실행한다. 자바 객체 ↔ DB 테이블을 이어주는 게 ORM(JPA).

## 📌 핵심 내용
- **의존성**: `spring-boot-starter-data-jpa`(ORM), `com.h2database:h2`(DB), `spring-boot-h2console`.
- **application.yaml**: `ddl-auto: update`(테이블 자동 생성/변경), `show-sql`+`format_sql`+`highlight_sql`(SQL 로그), `profiles.active: dev`.
- **프로필 분리**: dev = 파일 DB(`jdbc:h2:./db_dev`, 데이터 유지), test = 메모리 DB(`jdbc:h2:mem`, 매번 초기화). 테스트에 `@ActiveProfiles("test")`.
- **Question 엔티티 어노테이션**:
  - `@Entity`: 이 클래스를 테이블로 매핑.
  - `@Id`: 기본키.
  - `@GeneratedValue(strategy = IDENTITY)`: PK 값을 DB가 자동 증가.
  - `@Column(length = 200)`: varchar 길이. `@Column(columnDefinition = "TEXT")`: TEXT 타입.
- **이름 규칙**: 자바 카멜케이스 `createDate` → DB 스네이크 `create_date` 자동 변환.

## 🔎 디버깅 정리 (실제 값)
- `./gradlew build` → BUILD SUCCESSFUL (test는 test 프로필, 메모리 H2).
- 앱 실행(dev 프로필) 로그: `The following 1 profile is active: "dev"`, `Started SbbApplication in 7.022 seconds`.
- Hibernate 자동 생성 DDL(실제 로그):
  ```
  create table question (
      id integer generated by default as identity,
      content TEXT,
      create_date timestamp(6),
      subject varchar(200),
      primary key (id)
  )
  ```
- 매핑 결과: int→integer(identity PK), String+length→varchar(200), columnDefinition=TEXT→TEXT, LocalDateTime→timestamp(6).
