# 01단원: 프로젝트 뼈대

## 🧠 머릿속 그림 요약
`main()` → `SpringApplication.run()` 한 줄이 스프링 컨테이너를 부팅하고 내장 Tomcat을 띄운다.
`@SpringBootApplication`이 ①자동 설정 ②컴포넌트 스캔 ③설정 클래스 역할을 한 번에 켠다.
빌드 설정(`build.gradle.kts`)이 "무엇을 쓸지(의존성)·어떤 자바로(25)·어디서 받을지(mavenCentral)"를 정의한다.

## 📌 핵심 내용
- **build.gradle.kts**: 설계도. `spring-boot` 플러그인 + `dependency-management`가 버전 자동 관리. `starter-webmvc` = Tomcat + Spring MVC. Lombok/devtools 포함.
- **settings.gradle.kts**: 프로젝트 이름 `sbb`.
- **application.yaml**: 스프링 설정(현재 앱 이름만).
- **SbbApplication.java**: 진입점. `@SpringBootApplication` + `main`의 `SpringApplication.run(...)`.
- **SbbApplicationTests.java**: `@SpringBootTest`로 컨텍스트 로딩만 검증(`contextLoads`).

## 🔎 디버깅 정리 (실제 값)
- `./gradlew build` → **BUILD SUCCESSFUL in 56s**, 7 tasks executed.
- `:test` 태스크에서 `contextLoads()` 통과 = 스프링 컨텍스트가 정상 기동됨을 의미.
- Gradle 9.4.1 배포판 최초 1회 다운로드됨.
