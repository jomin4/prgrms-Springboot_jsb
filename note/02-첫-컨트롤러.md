# 02단원: 첫 컨트롤러

## 🧠 머릿속 그림 요약
브라우저 요청 → 내장 Tomcat → DispatcherServlet(프론트 컨트롤러)이 URL을 보고 알맞은 메서드로 배분 → `@GetMapping`으로 매칭된 컨트롤러 메서드 실행 → `@ResponseBody`가 반환 String을 HTTP 응답 본문으로 내보냄 → 브라우저에 표시.

## 📌 핵심 내용
- **@Controller**: 이 클래스가 웹 요청을 처리하는 컨트롤러임을 선언. 컴포넌트 스캔으로 자동 등록.
- **@GetMapping("/path")**: 해당 URL의 GET 요청을 이 메서드에 연결.
- **@Controller vs @ResponseBody 차이(핵심)**:
  - `@ResponseBody` 없이 반환하면 → 반환값을 **뷰(템플릿) 이름**으로 해석 (6단원 Thymeleaf에서 활용).
  - `@ResponseBody` 있으면 → 반환값을 **HTTP 응답 본문 그 자체**로 전송 (텍스트/JSON 직접 응답).
- MainController: `/` → "SBB", `/hello` → "안녕하세요 ^ ^".

## 🔎 디버깅 정리 (실제 값)
- `./gradlew build` → BUILD SUCCESSFUL.
- 앱 실행(`java -jar build/libs/sbb-0.0.1-SNAPSHOT.jar`) 후 요청:
  - `GET /` → HTTP 200, Content-Type `text/plain;charset=UTF-8`, body `"SBB"`
  - `GET /hello` → HTTP 200, body `"안녕하세요 ^ ^"`
- 기동 로그: `Tomcat started on port 8080 (http)` → `Started SbbApplication in 2.683 seconds` → 첫 요청 시 `Initializing Spring DispatcherServlet 'dispatcherServlet'`.
