# 08단원: 답변 기능 (첫 POST, 양방향 연관관계, PRG)

## 🧠 머릿속 그림 요약
답변 폼 제출(POST /answer/create/{id}) → AnswerController가 질문 조회 후 AnswerService.create로 답변 INSERT(question_id FK로 질문에 연결) → `redirect:`로 HTTP 302 응답 → 브라우저가 자동으로 GET /question/detail/{id} 재요청 → 상세 페이지가 question.answers를 목록으로 렌더. (Post-Redirect-Get 패턴)

## 📌 핵심 내용
- **첫 쓰기 요청**: `@PostMapping` + `@RequestParam String content`로 폼(textarea name=content) 값 수신. (지금까지는 전부 GET 읽기)
- **양방향 연관관계**: Answer(N)=주인 `@ManyToOne Question question`(FK 보유), Question(1)=거울 `@OneToMany(mappedBy="question", cascade=REMOVE) List<Answer> answers`. mappedBy가 "주인은 Answer.question"이라 선언 → question 테이블에 새 컬럼 안 생김. 덕분에 상세에서 question.answers로 답변 목록 접근.
- **PRG(Post-Redirect-Get)**: 저장 후 HTML 직접 반환하지 않고 `return "redirect:/question/detail/%d".formatted(id)` → 302. 새로고침 시 POST 재전송(중복 등록) 방지.
- **계층**: AnswerController → AnswerService.create(question, content) → AnswerRepository.save. 질문 조회는 재사용된 QuestionService.getQuestion.
- 상세 템플릿: `#lists.size(question.answers)` 답변 수, `th:each="answer : ${question.answers}"` 목록, 작성 폼(form method=post).
- (배경) OSIV(open-in-view 기본 on) 덕에 템플릿 렌더 중 answers 지연로딩 가능.

## 🔎 디버깅 정리 (실제 값)
- build: BUILD SUCCESSFUL, 기존 테스트 유지.
- 답변 0개 질문 `/detail/2` → h5 "0개의 답변이 있습니다." (빈 목록 정상 렌더).
- `POST /answer/create/1` (content=…) → HTTP 302, Location `/question/detail/1`.
- 리다이렉트 후 `/detail/1` → "1개의 답변이 있습니다." + "폼으로 등록한 첫 답변입니다." 렌더.
- answer INSERT 바인딩: `(3:INTEGER) <- [1]` = question_id(FK)=1 → 답변이 질문 1에 연결됨.
