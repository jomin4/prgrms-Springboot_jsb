# 04단원: 연관관계 (Answer, @ManyToOne 1:N)

## 🧠 머릿속 그림 요약
객체 세상: `Answer`가 `Question` 객체를 **참조**로 가짐(`@ManyToOne private Question question`). 답변 여럿(N) → 질문 하나(1).
DB 세상: 참조가 없으니 Hibernate가 이를 **`question_id` 외래키 컬럼**으로 변환하고, `question(id)`를 가리키는 **FK 제약**을 건다. 관계의 N쪽(answer)이 외래키를 가진다.

## 📌 핵심 내용
- **@ManyToOne**: "다(N) 대 일(1)". 이 어노테이션이 붙은 필드가 있는 엔티티(Answer)가 N쪽 = 외래키 보유.
- 자바 필드명 `question` → DB 컬럼 `question_id`(필드명 + _id).
- FK 제약으로 두 테이블 연결. question 테이블엔 answer 관련 컬럼이 생기지 않음(단방향).

## 🔎 디버깅 정리 (실제 값)
- `./gradlew build` → BUILD SUCCESSFUL.
- dev 프로필 기동 시 Hibernate 자동 생성 DDL:
  ```
  create table answer (
      id integer generated by default as identity,
      content TEXT,
      create_date timestamp(6),
      question_id integer,
      primary key (id)
  )
  alter table if exists answer
     add constraint FK8frr4bcabmmeyyu60qt7iiblo
     foreign key (question_id) references question
  ```
- `@ManyToOne private Question question` → `question_id integer` 컬럼 + FK로 변환 확인.
