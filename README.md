# prgrms-Springboot_jsb

Spring Boot 학습 프로젝트 — 강사 jhs512의 SBB(질문/답변 게시판) 강의를 따라 단계별로 구현합니다.

- **스택**: Spring Boot 4.0.6 · Java 25 · Gradle(Kotlin DSL) · Lombok · Thymeleaf · JPA/H2
- **참고**: https://www.slog.gg/p/14163
- **진행 방식**: 챕터별로 학습 → 각 챕터 마무리 시 원격에 반영

## 진행 현황

| 챕터 | 내용 | 상태 |
|------|------|------|
| 1 | 프로젝트 뼈대 | ✅ 완료 |
| 2 | 첫 컨트롤러 (@Controller, 요청/응답) | ✅ 완료 |
| 3 | JPA + 엔티티 (Question, DB 테이블 자동 생성) | ✅ 완료 |
| 4 | 연관관계 (Answer, @ManyToOne, 외래키) | ✅ 완료 |
| 5 | 레포지토리 + 테스트 (JpaRepository, 저장/조회) | ✅ 완료 |
| 6 | 서비스 계층 (@Service, DI, 예외 처리) | ✅ 완료 |
